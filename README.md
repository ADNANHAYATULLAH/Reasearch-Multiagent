
# 🔬 ResearchForge AI

A modular multi-agent research application built with:

- Streamlit
- CrewAI
- Groq / Llama 3.3 70B
- DDGS live web search
- Requests + BeautifulSoup web page extraction

## Agents

1. Research Manager
2. Web Researcher
3. Source Analyst
4. Fact Checker
5. Report Writer

## Run

The application is designed for Streamlit Community Cloud.

Add this secret:

```toml
GROQ_API_KEY = "your-groq-api-key"
```

Then deploy `app.py`.
